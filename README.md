# Thesis Supply Storefront

A ready-to-run Vite + React + TypeScript + Tailwind CSS project containing the supplied storefront mockup.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy / preview online

You can import this folder or its ZIP into StackBlitz. StackBlitz should install dependencies from `package.json` automatically. If it does not, open its terminal and run `npm install`.

## Notes

- Tailwind CSS v4 is configured through the Vite plugin.
- `lucide-react` is included for the icon imports in `src/App.tsx`.
- The supplied storefront is a frontend mockup. Its checkout interaction is demonstrative and does not process real payments or persist orders.
